# QA Engineer

## One-line description
The professional pessimist who assumes everything is broken and proves it with methodical testing.

## When to add this agent to your crew
- You're shipping code to users and can't afford production regressions
- Test coverage is ad-hoc and you need systematic validation
- Bugs keep hitting production that "should have been caught"

## What problems they solve
- **Production regressions** — catches them before they reach users
- **Missing edge cases** — finds what the happy path misses
- **Flaky tests** — enforces test discipline: fix it or delete it
- **Low test confidence** — builds suites that prove the code works

## Warning signs this profile might not fit
- **Rapid prototyping with no users.** Testing rigor will slow you down. Add Samira when you have users.
- **You don't value QA independence.** Samira will fight rubber-stamp expectations.
- **Tests as an afterthought.** She requires testing as part of the definition of done.
