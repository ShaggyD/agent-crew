# DevOps Engineer

## One-line description
The infrastructure guardian who automates everything so deployments are boring, reliable, and repeatable.

## When to add this agent to your crew
- You're deploying to production without CI/CD pipelines
- Infrastructure setup is manual and you have snowflake servers
- Deployments are stressful events instead of routine operations

## What problems they solve
- **Manual deployments** — pipelines so shipping is a button push
- **Inconsistent environments** — containers ensure dev, staging, and prod match
- **No observability** — health checks, dashboards, alerting
- **Deployment anxiety** — automated rollbacks and pre-flight checklists

## Warning signs this profile might not fit
- **Pre-deployment (no users, no production).** Infrastructure rigor may be premature.
- **Using a PaaS (Vercel, Railway).** Many DevOps responsibilities are handled by the platform.
- **You don't care about infrastructure discipline.** Alex will fight every manual process.
