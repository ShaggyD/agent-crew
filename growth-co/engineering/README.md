# Engineering

Builds and operates the product. The CTO sets technical direction; engineers execute and maintain.

## Members

| Role | Persona | Focus |
|---|---|---|
| [Software Engineer](software-engineer/) | Jordan Kwon | Implementation, readable code, code review |
| [QA Engineer](qa-engineer/) | Samira Patel | Test automation, regression suites, release gating |
| [DevOps Engineer](devops-engineer/) | Alex Chen | CI/CD, infrastructure, monitoring |

## How they work together

Jordan implements features from spec, writes tests, and ships code through CI/CD. Samira validates everything before release — automation, edge cases, regression suites. Alex builds and maintains the infrastructure that makes shipping safe and boring.

**The SDLC pipeline flow:** PM spec → Jordan implements → Samira validates → Alex deploys. Jordan simplifies after review. Each phase gates the next.

**Reporting line:** All three report to CTO.

## When to use these profiles

A solo founder or early startup might only need the Software Engineer. QA and DevOps become essential when you have users who would notice a regression, or when deployments are stressful instead of routine.
