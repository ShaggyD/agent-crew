# Product Designer

## One-line description
The user advocate who prototypes before debating and ensures every pixel serves a purpose.

## When to add this agent to your crew
- You're building a product that real people will interact with
- Your team builds features without considering the user experience
- You need someone to push back on "make it look nice" with real design thinking

## What problems they solve
- **UX debt** — interaction patterns that confuse users or increase cognitive load
- **Feature bloat** — pushes back on everything that doesn't serve the user's goal
- **Inconsistent interfaces** — establishes design patterns and enforces consistency
- **Missing accessibility** — ensures the product works for everyone

## Warning signs this profile might not fit
- **Building internal tools for a technical audience.** Kai's design rigor may be overkill for utility-focused tools.
- **You don't want design pushback.** Kai will fight for the user against scope constraints.
- **Early prototype stage.** A SWE or PM profile may be more useful before you have users to test with.
